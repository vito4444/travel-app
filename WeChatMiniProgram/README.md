# 行程管家 · 微信小程序版

与 iOS 版（仓库根目录 `TripKeeper/`）同一套功能与界面设计的微信小程序实现：行程时间轴、地图路线优化并自动回写行程、订票平台跳转、订票短信离线解析导入、行前清单、预算记账、天气、足迹统计与行程分享。原生小程序写法（WXML/WXSS/JS），零构建链、零 npm 依赖，数据全部存微信本地缓存。

## 在微信开发者工具中运行

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 工具里选「导入项目」，目录选本文件夹（`WeChatMiniProgram/`）。
3. AppID：填你自己的小程序 AppID；没有就点「使用测试号」（游客模式，能跑全部功能，跳转其他小程序除外）。
4. 天气接口域名：开发调试在「详情 → 本地设置」勾选「不校验合法域名」即可；正式发布需在 [微信公众平台](https://mp.weixin.qq.com) → 开发管理 → 服务器域名，把 `https://api.open-meteo.com` 加入 request 合法域名。
5. 真机预览：工具栏「预览」扫码，用你的微信直接跑。

## 功能一览

- 行程管理：新建行程按起止日期自动生成每日日程；列表封面色卡显示倒计时/旅行中状态；长按卡片编辑或删除（删除有二次确认）。
- 每日时间轴：按天分组，天头部显示日期、星期与天气（Open-Meteo，免 key，超出 16 天预报窗口显示「—」）；点条目编辑，「调整顺序」模式下上移/下移/删除。
- 行程条目：航班/火车/酒店/景点/餐饮/交通/其他 7 类，表单字段随类型变化；地点用微信内置 `wx.chooseLocation` 地图选点（免地图 key）；可挂照片附件（存本地，最多 5 张）。
- 预订信息与跳转：条目关联平台、订单号、电话、小程序链接后，卡片出现「打开平台 / 打电话 / 复制订单号」按钮。跳转机制见下节。长按条目可打开位置卡片（内含跳第三方地图导航入口）。
- 地图路线规划：每日地图带序号标记与连线；「优化顺序」最近邻 + 2-opt（固定首尾）；分段交通时长按直线估算并标注「估算」；「应用到行程」把新顺序与推算时间写回，时间轴同步更新。
- 智能导入：粘贴 12306 购票短信、航班/酒店确认短信，本机离线正则解析生成条目，内置三个示例。
- 行前清单（五类模板一键导入、进度条）、预算记账（分类汇总、超支提示）、足迹统计（旅程数/天数/目的地/足迹地图）、分享（微信转发卡片 + 复制文本行程单 + Canvas 长图保存相册）。

## 平台跳转机制

微信小程序无法唤起外部 App，等价能力是跳转各平台的小程序（`wx.navigateToMiniProgram`，微信会弹确认框）：

- 携程：内置已确认的小程序 AppID（`wx0e6ed4f51db9d078`），一键直跳。
- 其他平台（去哪儿/飞猪/12306/美团/大众点评/艺龙/滴滴/航旅纵横）：在条目编辑里粘贴对方小程序的链接（打开对方小程序 → 右上角菜单 → 复制链接），即可一键直跳；未配置时自动复制订单号并提示去对应平台粘贴查单。未收录其他平台 AppID 的原因：无法从可靠公开来源确认，宁缺毋滥。

## 与 iOS 版的差异（微信平台限制）

- 无本地通知能力：出发提醒功能不提供（订阅消息需要后端），以行程卡片倒计时为准。
- 拖拽排序改为「调整顺序」模式的上移/下移。
- 路线分段时长全部为直线估算（接第三方路线 API 需要地图厂商 key），已在页面标注。
- 订单链接（H5 网页）在小程序内无法直接打开，用「小程序链接」字段替代。
